# MTAD Research Platform

A long-term personal research platform for **multivariate time-series anomaly detection**, built on top of [TSB-AD](https://github.com/TheDatumOrg/TSB-AD) (Liu & Paparrizos, NeurIPS 2024).

The platform supports iterating across multiple papers — including reproducible baseline benchmarks, clean ablations, and consistent figure/table generation — with a parallel `extensions/` layer that adds new detectors, metrics, and dataset loaders without forking the upstream benchmark.

*Site under construction. See the [repository](https://github.com/My-projects-portfolio/mtad-platform) for the current state.*
